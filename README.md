# OraxRecordly

مسجّل شاشة ومحرّر مفتوح المصدر لصناعة فيديوهات العرض والشرح، مع لقطات شاشة ومحرّر صور مدمج.

---

## نسبة العمل إلى المشروع الأصلي

OraxRecordly فرع مشتق من [Recordly](https://github.com/webadderallorg/Recordly) للمطوّر [@webadderall](https://x.com/webadderall)، ويُستخدم بموجب رخصة المشروع الأصلية.

التطبيق الأصلي وتصميمه ومعظم هذا الكود هما من عمل مشروع Recordly والمساهمين فيه، ولا ينسب هذا الفرع ذلك العمل إلى نفسه. الرخصة الأصلية محفوظة كما هي في [LICENSE.md](LICENSE.md) — **AGPL-3.0**.

ولأن الرخصة لا تسمح بإعادة استخدام اسم «Recordly» أو هويته، يُوزَّع هذا الفرع باسم OraxRecordly.

---

## ما يميّز هذا الفرع

التسجيل والمخطط الزمني وأدوات المؤشر وتنسيق الإطار والتصدير إلى MP4 وGIF مزايا المشروع الأصلي كما هي. وما يلي هو ما أضافه هذا الفرع أو أصلحه.

- **واجهة عربية أولاً** مع تخطيط RTL كامل، ولغتان فقط: `ar` و`en`.

- **لقطات الشاشة**:
  - التقاط شاشة كاملة، أو نطاق محدد، أو المصدر المحدد، دون بدء تسجيل.
  - اختصار عام `Ctrl+Alt+A` يعمل من أي تطبيق، ويمكن تغييره أو تعطيله من الإعدادات.
  - تأخير التقاط، وقالب لاسم الملف مع معاينة، ومجلد حفظ مخصّص، وإخراج PNG أو JPEG.
  - مكتبة في لوحة التحكم للبحث في اللقطات وإعادة فتحها وإظهارها في مدير الملفات وحذفها.

- **محرّر الصور**: قص، حذف منطقة، قلم، سهم، أشكال، تظليل، تمويه، ونص، مع تراجع كامل وحفظ بلا فقدان.

- **خلفيات من جهازك**: خلفيات مدمجة، وألوان وتدرّجات، واكتشاف تلقائي لأي خلفية تضعها في مجلد الخلفيات.

- **إصلاح إنهاء التسجيل**: كان مساعد الالتقاط على Windows يعيد ترميز إطار مكرّر عن كل فجوة خاملة، فكان إيقاف التسجيل بعد شاشة ساكنة يستغرق زمن الخمول نفسه — خمول 20 ثانية كان يعني 23–42 ثانية لإيقافه — ثم يُقتل المساعد قبل كتابة ذيل الملف فيضيع التسجيل. صار الإيقاف الآن **0.1–1.3 ثانية مهما طال الخمول**، وحجم الملف أصغر بمراتب: **مقطع 20 ثانية صار 3.1 ميجابايت بدل 57.9 ميجابايت**.

- **تحسينات الأداء**: تقسيم شيفرة المحرر خفّض حزمة التحرير من 1347 كيلوبايت إلى 938 كيلوبايت، مع إزالة الاستعلامات المتكرّرة أثناء التسجيل.

- **إزالة تسجيل الدخول والسحابة**: لا حساب ولا مشاركة سحابية ولا خدمات خلفية؛ التطبيق يعمل محلياً بالكامل.

- **التحديثات من هذا المستودع**: التحديث التلقائي يقرأ إصدارات هذا الفرع وحده، لا إصدارات المشروع الأصلي.

## التنزيل والتحذير

نزّل المُثبِّت من [صفحة الإصدارات](https://github.com/Mohammedorax/OraxRecordly/releases). على Windows يكون الملف `OraxRecordly-windows-x64.exe`.

> **تنبيه:** البناء غير موقّع رقمياً، لذا قد يعرض SmartScreen تحذيراً عند التشغيل. اضغط **مزيد من المعلومات** ثم **التشغيل على أي حال**.

**المتطلبات:** Windows 10 إصدار 19041 أو أحدث، أو Windows 11، بنسخة 64 بت.

---

## البناء من المصدر

المتطلبات:

- **Node.js** مع npm — إصدار LTS حديث.
- **على Windows:** Visual Studio 2022 (أو Build Tools) مع حمل عمل **تطوير سطح المكتب باستخدام C++**، بالإضافة إلى **CMake** — لبناء مساعد الالتقاط الأصلي `wgc-capture`.
- **على macOS:** Xcode Command Line Tools — لبناء مساعدات الالتقاط الأصلية.

```bash
npm ci --ignore-scripts
npm run build:windows-capture   # Windows: بناء مساعد الالتقاط الأصلي WGC
npm run dev
npm run build:win               # حزمة NSIS لمُثبِّت Windows
```

أمر `npm ci --ignore-scripts` يثبّت الشجرة المقفلة دون تشغيل خطاف `postinstall` الذي يعيد بناء كل المساعدات الأصلية، لذا ابنِ المساعد الذي تحتاجه صراحةً كما في الأعلى. وللبناء لمنصّتك الحالية استخدم `npm run build`، وتخرج الحزمة في مجلد `release/`.

## التحديثات

يقرأ التطبيق الإصدارات من مستودع هذا الفرع، ويُعلمك داخل التطبيق عند توفّر تحديث، ولا يُثبّته إلا بموافقتك. تفاصيل إصدار التحديث ونشره في [docs/updates.md](docs/updates.md).

يتحقّق المُثبَّت من صفحة الإصدارات مرة واحدة عند التشغيل، ثم يكمل عملك دون مقاطعة.

يبقى مجلد بيانات المستخدم باسم `%APPDATA%\Recordly` عن قصد، حتى تُحفظ التسجيلات والإعدادات لمن كان يستخدم المشروع الأصلي.
